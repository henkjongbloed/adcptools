# ADCPtools examples

These examples are designed to run from any checkout location. They derive
the toolbox and sample-data paths relative to the example file rather than
using paths specific to an individual computer.

| Example | Purpose | Data |
| --- | --- | --- |
| `quick_start_vmadcp.m` | Read, construct, and inspect an RDI vessel-mounted ADCP dataset | Bundled Muara Muntai Bend deployment |

Run an example from MATLAB with:

```matlab
run('examples/quick_start_vmadcp.m')
```

For a fuller explanation of each analysis step, use the MATLAB help opened by
`open_adcptools_documentation`.
